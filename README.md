# Axé Cria

Site da produtora cultural **Axé Cria**, desenvolvido como projeto de grupo da disciplina de Engenharia de Software para demonstrar o uso de **GitHub + Cloud (Vercel)** com deploy automático.

🔗 **Site online:** [(https://axe-cria-landing-six.vercel.app/)]

## Tecnologias

- HTML
- CSS
- JavaScript
- Git e GitHub (versionamento e trabalho em equipe)
- Vercel (hospedagem em nuvem e deploy automático)

## Como abrir o projeto

1. Clone o repositório:
```bash
   git clone [cole aqui o link do repositório]
```
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server).

## Como funciona o deploy automático (CI/CD)

1. Alteramos o código no computador.
2. Enviamos para a branch `main` do GitHub (`git add .`, `git commit`, `git push`).
3. A Vercel detecta a mudança na `main`.
4. Ela faz o build e o deploy sozinha, e o site atualizado fica online em segundos.
